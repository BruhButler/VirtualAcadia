# Virtual Acadia 🎓🌲

**Capstone Project - Acadia University (COMP 4983)**  
Created by **Joshua Butler**

## 📌 Overview

**Virtual Acadia** is a 3D campus exploration software developed as a capstone project for the Jodrey School of Computer Science at Acadia University. It provides a virtual tour experience for prospective students or anyone curious about the Acadia campus, especially those who can't visit in person.

Users can walk through a stylized version of the Acadia campus, collect interactive items, and explore recognizable landmarks—all built using open-source tools and technologies.

## 🛠 Technologies Used

- **Godot 4.4 (Mono Edition)** – Game engine for implementation  
- **GDScript** – Scripting logic (similar to Python)  
- **Blender** – 3D modeling of terrain and buildings  
- **xNormal** – Used for generating heightmaps from 3D models  
- **OpenStreetMap & Terrabrush** – Map data and terrain generation  
- **GitHub** – Version control and collaboration  
- **Online texture libraries** – For realistic surface details

## 🎮 Features

- Free-roam 3D environment of the Acadia campus  
- Custom-built terrain with stylized shaders  
- Retro-style rendering using post-processing effects  
- Interactive coin collection mini-game  
- Collision and LOD (Level of Detail) optimizations  
- Modular scene loading for buildings and environments
